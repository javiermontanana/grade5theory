--- layout: chapter tilte: Treble Clef ---

If we want to be able to write all the notes in a very wide range, let's say the whole range of the piano. In treble clef, to write middle C we already need to use a ledger line, We could use more and more ledger lines to write lower and lower notes, but it quickly becomes hard to read and write these.

By using a different clef, we can centre the stave on a different set of notes, (a different register). This will allow us to write *those* notes without ledger lines, and we will need ledger lines for any notes outside that range.
