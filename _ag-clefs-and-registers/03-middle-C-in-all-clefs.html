Now that we know what each clef means, we can place a given pitch on any clef. Let's start by placing middle C in all 4 clefs:

Treble Clef

You probably already know where middle C is, but let's use the definition of the clef that we learnt earlier. The G clef on the second line tells us that that is where the note G is, and that is the G above middle C, so middle C is a fifth down from it.

Bass Clef

The F clef on the 4th line is the F below middle C, so middle C is a fifth above:

Alto and Tenor Clefs

The C clef is centred on middle C, so in alto clef it will be on the third line, and in tenor clef on the fourth line.
