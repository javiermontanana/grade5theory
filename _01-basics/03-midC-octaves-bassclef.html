Middle C

The C on the first ledger line below the staff in treble clef is known as middle C.

This is because it is near the middle of the piano keyboard. On a piano keyboard, you can find a C by going to the white key just to the left of a pair of black keys.

Octaves

The next C above middle C is on the third staff space.

The distance (or interval) between those two notes is called an octave. Octave comes from the latin word for eight, and if you start counting up from middle C, the next C is note number 8.

An interval is just the way we describe the distance in pitch between two notes. There is a whole chapter on intervals, where you will learn to fully describe any interval. But for now you should know that we count in this way: starting at the bottom note and counting up as we go up a staff position.

Because we have 7 letter-names for the notes, if we start on any note and count up, note number 8 (the octave) will always have the same letter-name as the one we started with.

Notes of the same letter-name share a special relationship. They sound "the same as each other but higher or lower."

The octave relationship is so fundamental, that sometimes we will say that the two C's are "the same note in a different octave."

Bass Clef

Speaking of higher and lower notes, the staff in treble clef is very useful for writing the notes that are higher than middle C. But for middle C we already need to use a ledger line, and half of the piano keyboard is lower than middle C. This means that if we want to write those lower notes, we are going to need a lot of ledger lines.

There is another solution. Instead of treble clef, we can use bass clef.

Bass clef looks like this:

The bass clef symbol represents the note F and places it on the 4th staff line. The staff and the note names still work in the same way: so one staff position higher means one letter-name higher.

In bass clef, middle C is the note on the first ledger line above the staff.

So the notes on the staff in bass clef are all lower than the notes on the staff in treble clef, which makes bass clef more suitable for writing music that uses lower notes.
