--- layout: chapter title: Transposing key signatures ---

Usually, when we transpose, we will have to change the key signature.

The way we will do this is to work out what key the key signature belongs to. Here we can work out either the major or the minor key. It doesn't matter which we choose, but we need to stick to the same one. If we use major, we need to stick with major. If we use minor we need to stick with minor.

Then we move the tonic of the key by the interval of transposition. Then we work out the key signature for the new key, which will be our new key signature.

Let's see this with an example.

Suppose we have the following key signature, and we need to transpose it up a major second.

This key signature belongs to D major.

A major second up from D is E, so we need the key signature for E major, which is 4 sharps.

Let's check that it doesn't make a difference if we use the minor key. In that case, we would say that this is the key signature for B minor. Up a major second from B is C sharp, so we need the key signature for C sharp minor. The key signature of C sharp minor is 4 sharps, so we get the same answer. Just make sure you stick with either major or minor keys for this process.
