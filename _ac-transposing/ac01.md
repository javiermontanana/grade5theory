## What is transposing

Transposing is simply moving a set of notes up or down by a certain interval. (This interval is called the interval of transposition.)

Let's take a simple example. We if we wanted to transpose the following melody up a perfect 5th,
do re mi

we would obtain the following: 
sol la si

if instead we want to transpose it up by an octave, we would have this:
do re mi

As you can see, to be able to transpose, you need to know your intervals well. You will also need to know your keys and scales. 
(We already did a little bit of transposing in section 12 of the chapter on keys and scales.)
The good news is that if you are confident with those, it's quite straighforward.

## transposing the key signature

Usually, when we transpose, we will have to change the key signature. In this case, we must make sure we transpose the key signature properly. 

The way we will do this is to work out what key the key signature belongs to. Here we can work out either the major or the minor key. It doesn't matter which we choose, but we need to stick to the same one. If we use major, we need to stick with major. If we use minor we need to stick with minor. 

Then we move the tonic of the key by the interval of transposition. Then we work out the key signature for the new key, and that gives us our new key signature. 


Let's see this with an example. 

Suppose we have the following key signature, and we need to transpose it up a major second. 

This key signature belongs to D major. 

A major second up from D is E, so we need the key signature for E major, which is 4 sharps. 


Let's check that it doesn't make a difference if we use the minor key. In that case, we would say that this is the key signature for B minor. Up a major second from B is C sharp, so we need the key signature for C sharp minor. The key signature of C sharp minor is 4 sharps, so we get the same answer. 

Just make sure you stick with either major or minor keys for this process. 

As you practise and become better at this, you will see that for each interval of transposition, we move a certain number of steps up or down the table. You already know that this is the case for transposing by a perfect fifth: we move by one row on the table, well it is also true for anty other interval. With practice, you will learn the patterns for a few different intervals, but to begin with, I would stick to the method explained above.

## why is it important and useful

If you look at the example of Happy Birthday (or any of the other examples, for that matter) 
I hope you understand that when we transpose a tune, we still have the same tune. 
All the notes are different, but we still hear it as the same tune. 

If a person with a low voice sings a certain song in a register that is comfortable for them, 
and a person with a high voice sings it in a register that is comfortable for them,
they probably won't sing the same notes. 
The song will be transposed higher or lower but it is still the same song!

This may seem very obvious to you, or it may seem very surprising. 
Either way, you should think about it, because it says something important about how we perceive music. 
Most of us don't identify notes in an of themselves. 
Instead, we identify the relationships between the notes (intervals).

If someone plays you this today: 
B

and this tomorrow:
A

If you're like most people, you won't be able to say wether that was the same note or a different one. 


But if they play this:
BAG

and then this
GBA

and they ask "is it the same tune?"
then you should be able to say no, if you were able to remember the tune for one whole day. 

if they play you this
GAF

and this 
ABG

then you should say yes. 

These two are the same tunes transposed, and most of us can't tell that one is higher than the other if we hear them 24 hours apart, we just hear it as the same tune. 


For this reason, 
being able to transpose means you are able to understand what the same tune would look like if it's moved a bit higher or lower, sung by a different register voice, played by a different register instrument or moved to a different key. 
It is an essential part of being properly fluent with music.
