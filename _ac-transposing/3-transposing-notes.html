Now that we are able to transpose the key signature, we need to transpose the notes.

We will look at 3 different ways, all of which are valid:

  • move each note by the interval of transposition
  • move the first note by the interval of transposition, then follow the intervals in the melody.
  • work out the melody as scale degrees in the key, then the transposed melody will be the same scale degrees in the new key. (obviously keep it in the right register and octave)

The first note is C so a major 2nd higher is D. The second note is F becomes G. The third note E becomes F# (because we have done the key signature correctly, that takes care of the sharp.) and so on

Method 3

Let's now transpose our example up a perfect 5th, usign the third method. To do this, I will first have to wrok out what the scale degrees are.

Up a perfect 5th from C is G, so our answer will have these scale degrees in G major. The key signature will be 1 sharp

Scale degree 1 is G Scale degree 4 is C and so on

Here we need to be a bit careful with what octave we go to. We want to transpose up a 5th, so we need to use the G above middle C. The second note will be the C above that.

You need to keep track of the outline, of the melody to make sure that you don't go to the right notes in the wrong octave.
