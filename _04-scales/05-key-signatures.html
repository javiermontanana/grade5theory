Keys

A piece of music that uses notes from a certain scale is said to be in the key of that scale. A piece (or part of a piece) that uses notes from the D major scale is said to be in the key of D major. (This is an oversimplification and you will learn more about keys later in the chapter, but it will do for now.) In this case, the music would contain a lot of F sharps and C sharps. Rather than writing a sharp whenever a C♯ or an F♯ comes up, we can use a key signature.

Key signatures

A key signature is a set of sharps or flats placed at the beginning of each stave, next to the clef. These sharps or flats will apply to any notes of that letter name. So, for example, if we have a piece with an F♯ in the key signature, any Fs will automatically be sharp. When the note F♮ appears, it will use the accidental ♮ sign. Each key has it's corresponding key signature.

This is what a D major scale looks like if we use a key signature, instead of writing each sharp next to its note.

Order of sharps and flats

If you look back at all the major scales we worked out earlier in this chapter, you can see how many sharps or flats each scale has. G major has one sharp (F♯), D major has two (F♯ and C♯), F major has one flat (B♭) and so on...

You will also see that there is an order to the sharps and flats that is never broken. F♯ is the first, C♯ is the second, and so on. By this I mean that there isn't a scale where the C is sharp but the F isn't. F♯ is the first sharp, so it is there in all the scales with one or more sharps. Same for the flats, B♭ is the first, E♭ is the second...

The order of sharps is the following: F - C - G - D - A - E - B

The order of flats is the following: B - E - A - D - G - C - F

There are a couple of things we can notice that will make it very easy to remember.

  • The order of flats is exactly the reverse to that of the sharps.
  • Each sharp is a fifth up from the last, so all you need to remember is that F is the first, and then you should be able to list all of them.
  • Since the order of flats is the reverse to the sharps, each new flat is a fifth down from the last.

Writing key signatures

There are a few conventions we should follow when writing key signatures:

  • Each sharp or flat should be written only once. The sharps and flats in the key signature apply to any notes of that letter name in any octave. They should only be written in one octave.
  • The sharps or flats should be in the right order. If we read the key signature from left to right, the first sharp should be F, the second C, and so on. For flats, the first should be B, the second E and so on.
  • Each sharp or flat should be in the right octave on the stave. In each clef, there is a conventional position for each sharp or flat. For example, in treble clef, the first sharp goes on the top stave line, not on the bottom space even though both of them would be a valid F♯. The way to learn these positions is to memorise what the key signatures with 7 flats and 7 sharps look like in each clef.

These conventions are followed universally nowadays, and will be followed in most printed music that you are likely to see. However, they are not always followed in some older editions. In the grade 5 theory exam, you are expected to know and follow them.
