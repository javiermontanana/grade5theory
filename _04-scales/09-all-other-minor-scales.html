--- layout: chapter title: Scales 9 - All Minor Scales ---

Now that we have learnt about A minor, we can work out all the other minor scales with all the different key signatures. These will work in a very similar way to the major scales: we will go up a perfect fifth to go up one more sharp (or one fewer flat) and we will go down a perfect fifth to go up one more flat (or one fewer sharp).

As an example, let's work out the minor key with one flat. From A we go down a perfect fifth and we get to D, so the key with one flat is D minor.

For the natural minor scale we just use the key signature, so the only note that is not natural is B♭.

For the harmonic minor scale, we raise note 7, so note 7 will be C♯.

For the melodic minor scale, we raise notes 6 and 7 going up, so note 6 is B♮ and note 7 is C♯, but going up only. So going down, note 7 is C♮ and note 6 is B♭.
