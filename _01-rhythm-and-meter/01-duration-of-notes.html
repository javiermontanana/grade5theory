This chapter is about rhythm and meter. These are to do with how sounds are organised in time. In this chapter we will not be concerned with pitch, i.e. which note is being played, only with when the notes (and rests) happen, and how they are organised into bars and beats.

Note values

When we speak about note values, we are talking about the length or duration of a note. A note has a notehead, which is placed on a certain position on the staff, indicating the pitch. The shape and appearance of the note indicates the note value. You should know and be familiar with the following note values.

Breve
Semibreve
Minim
Crotchet
Quaver
Semiquaver
Demisemiquaver

In the table above, each note value is half of the one above. So a minim is equivalent to 2 crotchets, or 4 quavers, etc.

If you have learnt that a crotchet is one beat and a minim is 2 beats and a quaver is half a beat, you must forget that because that is not always the case. That is a useful way of starting to learn about rhythm and note values, but it is not always true. Instead, we can say is that a minim lasts for 2 crotchets and a crotchet lasts for 2 quavers. What is a beat is something we will learn about later when we learn about time signatures.

Values shorter than the crotchet have a tail or flag coming out of the stem. The shorter the note value, the more flags the note has, with each flag indicating an additional halving of the note value.

When several notes shorter than a crotchet occur together, it is common to connect the flags so that they become beams. Then quavers will have 1 beam coming out of the stem, semiquavers will have 2 and demisemiquavers will have 3.

Dots

A dot next to a note adds half of its value to that note.

So a dotted crotchet is equivalent to a crotchet plus a quaver, or 3 quavers. A dotted minim is equivalent to a minim plus a crotchet, or 3 crotchets. Etc.

These dots should not be confused with staccato dots, which are placed above or below a note and indicate that the note should be played staccato.

Double Dots

A note can also be "double-dotted" meaning it has 2 dots. The second dot adds half of the value of the first dot.

In principle, there could be more than two dots, and each dot will add half of the value of the previous dot, but it's unusual to see more than 2.

Ties

A tie is a curved line that connects 2 notes, and means that they should be played as a single note whose value is the sum of the two.

So for example, a crotchet tied to another crotchet would be a note that lasts for two crotchets (or a minim).

This can be very useful if we want a note to start in one bar and finish during the following bar.

or if we want a note to last several bars.

We will later see that ties are sometimes also used to for notes that start in one beat of the bar and go into the next beat.

Ties and slurs

Ties look exactly the same as slurs, and can be easily confused. Slurs indicate that notes should be played in a smooth and connected way but don't affect the duration of the notes.

Ties will always connect notes of the same pitch, whereas slurs can connect notes of different pitch.

Rests

Rests indicate a silence. Rests have values, just like notes. Here are the corresponding rests for each note.

Breve
Semibreve
Minim
Crotchet
Quaver
Semiquaver
Demisemiquaver

Just like notes, rests can be dotted, and double dotted.

Rests can't be tied. As there is no sound being produced during the rest, it makes no sense to say that we will take two rests and combine them into one whose value is the sum. The result is exactly the same.
