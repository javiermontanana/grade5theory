--- layout: chapter title: Groupings ---

As we saw in the previous section, a series of quavers can be beamed in different ways. There are some rules or best practices that composers and publishers tend to follow to make it easier for perfomers to read and understand the structure of the rhythm on the page. Performers generally feel the pulse of the beats in the music as they perform, having the notes (and rests) grouped into beats so that the eye can pick up each beat as a separate unit on the page can be very helpful.

In this section we look at those best practices for writing rhythms. There are 3 kinds of decisions that we may need face that relate to this:

  • how to group beamed notes (quavers and shorter values)
  • writing longer rests as a single value or splitting them into shorter values
  • writing longer notes as a single value or splitting them into shorter values joined by ties

The rules for this get really quite complicated, But an awareness of the general principle behind them (to allow the performer's eye to pick up each beat) can get you a long way towards solving most cases.

Grouping in simple time

When there are 2 or 3 beats in a bar it is ok to beam several beats together.

When there are 4 beats in a bar, it is ok to group beats 1 and 2 (the first half of the bar), and it is ok to group beats 3 and 4 (the second half of the bar), but it is not ok to group beats 2 and 3. Each half should remain separate.

For rests, each beat should have a separate rest, except when there are 4 beats in a bar, it is ok to have a single rest for either the first half or the second half of the bar.

Grouping in compound time

Each beat should have a separate beam.

Where a single note lasts for 2 or 4 whole beats, a single note value may be used. But if a note, takes up some fraction of a certain beat, the start of a new beat should be visible with a new note and a tie.

For rests, each beat should have a separate rest, except when there are 4 beats in a bar, it is ok to have a single rest for either the first half or the second half of the bar.

When there are rests for a fraction of a beat. You should show each subdivision.

The rules for grouping get more complicated, but these are a good start and enough for the grade 5 exam. The principles behind the rules always remain the same: the aim is to aid legibility and to show the inner structure of the rhythm.

Remember that a whole-bar rest is shown as a semibreve rest, whatever the time signature. Never show the beats in a whole bar of rest.
