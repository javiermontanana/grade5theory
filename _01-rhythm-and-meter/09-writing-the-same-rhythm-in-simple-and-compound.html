But in the second beat, we run into a problem. We need 3 equal notes that divide the beat. This is what compound time signatures are desinged for, but we need to do it in a simple time signature. For this, we need to use something called a triplet.

Triplets

A triplet indicates that we will fit 3 notes where we would normally fit 2. In this case, we are 2/4 so the second beat is a crotchet, that which fits 2 quavers, and so by using a triplet we can fit 3 quavers.

Now we have the same rhythm,, but written in a compound time signature. Again, we will assume that our beat pulse is the same, and that will mean that it sounds the same. So it we had crotchet = 60 bpm in 2/4, we will need to have dotted crotchet = 60 bpm in 6/8

The triplet means that we are fitting 3 in the space of 2. So if the triplet is over a duration of a crotchet, it means that we are going to fit 3 quavers in that crotchet (normally, 2 quavers fit in a crotchet). But this doesn't necessarily mean that the triplet is going to contain 3 notes, which are quavers. Our triplet will contain note values which are equivalent to 3 quavers, but it can contain many different note values.

Duplets

Just like a triplet allows us to fit 3 in the space of 2, a duplet allows us to fit 2 in the space of 3.

This is going to be very useful when converting from a simple to a compound time signature.

Let's look at an example.

In the second beat, we have 2 notes each taking up half the beat.

For the first beat, we just need one note taking up the whole beat. That will be a dotted crotchet. For the second beat we need two notes, each taking up half the beat.

So what we will do is put a duplet over the second beat. This means that now we will fit just two quavers which will take up the space of 3.
