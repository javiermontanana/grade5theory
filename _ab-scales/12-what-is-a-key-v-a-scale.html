We have been using the words key and scale without properly defining them, to disinguish betweeen the two.

A scale is the set of notes when it is ordered stepwise, ascending or descending. Key is the environment of the music, so that it will have the tonic as it's final arrival point. Music that is in a certain key will generally use notes form the scale(s) of that key, and for the purposes of the grade 5 exam, you are absolutely fine to think of keys in this way. But as you learn more about how tonal music works, you'll understand that this is not strictly speaking true, and what really defines the key of the music is what note is the music directed towards so that it finds a sense of closure or resolution. For this, the relationship between the tonic and the dominant is crucial. In particular the way the dominant chord has a need of resolution toward the tonic chord. You'll learn more about this in the chapter on chords, but very briefly, the dominant chord is a set of notes which contains the leading note, which must be raised in minor keys so that it is a semitone away from the tonic. example of happy berthday ? in several keys?
