We have now formed all the major scales by starting with C major and

But what if we want to form a certain scale, let's say E major, without starting from C major? We want to start from the note E, which will be note 1 of the scale and, from here, form the whole scale.

We know the pattern of tones and semitones of the major scale, so we know that there are semitones between notes 3 and 4, and between 7 and 8.

Knowing this, let's work out the E major scale.

There is a tone between notes 1 and 2. Note 1 is E, so note 2 must be F♯.

There is a tone between notes 2 and 3. Note 2 is an F♯ so note 3 must be a G♯.

There is a semitone between notes 3 and 4. Note 3 is a G♯, so note 4 is an A.

There is a tone betweeen notes 4 and 5. Note 4 is an A so note 5 must be a B. It is also useful to remember and to check that note 5 is a perfect fifth above note 1 (B is a perfect fifth above E).

Tone between notes 5 and 6, so note 6 is a C♯

Tone between notes 6 and 7, so note 7 is a D♯

Note 8 is the same as note 1, so it's an E. We should check that notes 7 and 8 form a semitone, which they do.

What I've done here is not the only way of working out the major scale. For example, one could also use the fact that all the intervals up from note 1 are perfect or major (we learnt this in the chapter on intervals). Then you'd form a major second from E to get F♯, a major third to get G♯, a perfect fourth to get A, and so on. It doesn't matter what method you choose to use, but you should be able to form a major scale from any given note quickly and reliably.
