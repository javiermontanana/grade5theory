A chromatic scale is one where we go up a semitone each note. You can think of it as going through all the keys in the piano keyboard without missing any.

To write a chromatic scale in one octave, we will need to write 13 notes (12 plus the octave of the first one). Each note needs to be a semitone higher than the previous, but you can spell notes in different ways. There are many valid and correct ways of writing a chromatic scale.

  • There must be at least one note on each staff position.
  • There must not be more than 2 notes on each staff position.
