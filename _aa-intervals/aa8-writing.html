As well as being able to identify intervals, we need to be able write intervals. This means that if we are given a certain note, and an interval, we need to be able to write another note above or below it that forms that given interval. To be able to do this, we don't need to learn any thing new, we just need to use what we've already learnt to find such a note.

write a note that is a major 7th above the given note

As usual, we start with the interval number. The given note is a G, so we need to write an F above it.

We now have a 7th of some sort, but if we identify this interval we will see that it's a minor 7th. We therefore need to raise the note to an F♯ to make it a major 7th.

As you can see, in order to be able to write intervals, you need to be good at identifying intervals. If you can identify them well, you should be able to also write them. If you use everything you've learnt and identify all the intervals correctly at every stage, you should be able to do it without mistakes.
