Now that we are able to transpose the key signature, we need to transpose the notes.

We will look at 3 different ways, all of which are valid and should give you exactly the same result:

  • Method 1: move each note by the interval of transposition
  • Method 2: move the first note by the interval of transposition, then follow the intervals in the melody
  • Method 3: work out the melody as scale degrees in the key, then the transposed melody will be the same scale degrees in the new key

Method 3

Let's now transpose our example up a perfect 5th, usign the third method. To do this, I will first have to work out what the scale degrees are.

Up a perfect 5th from C is G, so our answer will have these scale degrees in G major. The key signature will be 1 sharp. The first note will be scale degree 1 (G), the second note will be scale degree 4 (C), and so on.

Here we need to be careful not to go to the right scale degree in the wrong octave. We want to transpose up a 5th, so we need to use the G above middle C. The second note will be the C above that. Make sure the transposed melody follows the same shape as the original melody.
