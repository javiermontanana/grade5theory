### ledger lines 

as we can see in the previous example, the 5-line staff allows us to write a few notes, 
but eventually we run out of space.  

In order to write notes that are above or below the staff, we use something called **ledger lines**
Ledger lines are little lines that we draw to extend the staff, just for a single note, 
When we need to we basically pretend that the staff has more than five lines, 
by just putting them in for the notes where they are required.

## treble clef and note names 

### treble 

The staff allows us to place higher and lower notes, 
but we haven't said what any of those notes are, we just know that they are higher or lower

In fact, we can't say what the notes are until we have something called a clef. 

The most common clef, and the only one we will learn about in this chapter is treble clef. 
(in the chapter on clefs, you will learn about other clefs.)
Treble clef looks like this: 
[picture]

and it tells us that the note on the second staff-line is a G. 

It does this because the treble-clef sign represents a G, 
and by placing the start of the loop on the second line, 
it indicates that the note on the second line note is G. 


### Notes names

Notes are named after the letters A-G, 
so there are 7 note-names. 

B is one step higher that A, 
C is one step higher than B, 
and so on. 
when we get to G, the next one is A again, and we repeat. 

Now we can name all the notes on the stave in treble clef:

## middle C 

The C on the first ledger line below the staff in treble clef is known as middle C. 
This is because it is near the middle of the piano keyboard. 


## octaves

As you can see, the next C above middle C is on the 3rd space. 
[picture] C C'

If we start counting up from middle C, the next C is note number 8. 
This is called a distance (or interval) of an octave. 

(When we count distances between notes,
how many notes apart they are,
we will always count both the bottom and top one.)

As we have 7 note-names, wherever we start counting from, 
note number 8 will always be the same letter as note number 1.
