--- layout: chapter title: Writing the same rhythm doubling or halving note values ---

In this section we will be rewriting a certain given rhythm in a new time signature by halving or doubling all the note values.

For this, our new time signature must have the same top number as the old one. The bottom number will be either double or half of the old one. Then we can double or halve the note values while keeping the same rhythm. Remember that what defines a rhythm is the placement of notes on the beats (or fractions of beats) of the bar. So we will change all the note values but keep the number of beats in a bar the same, and the placement of the notes within those beats the same.

We are going to try to write that rhythm using note values that are twice as long.

Let's think of our new time signature first. In 2/4 each beat is a crotchet, so in our new time signature the beats will have to be twice as long: minims. We will still need two beats in a bar. Remember that the number of beats in a bar is essential to the rhythm, and because we want to write the same rhythm we must not change the number of beats in a bar, so we must keep the top number the same.

Our new time signatue will therefore be 2/2, as it has 2 minim beats in a bar. In our new time signature, if we double the note values, we will have the same rhythm as before.

This is the same rhythm because we have notes being played on exactly the same fractions of the beats of each bar as we did before. In the first beat we have one note taking up the whole beat, and in the second beat we have one note taking up the first half, and another taking up the second half.

Remember that what is essential to the rhythm is the beats, so we are assuming that our beat pulse is the same. If that is the case, then the rhythm will sound exactly the same whether it is written in one time signature or another.
