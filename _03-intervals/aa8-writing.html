As well as being able to identify intervals, you will need to be able write intervals. This means that if you are given a certain note and a certain interval, you need to be able to write another note above or below it that forms that interval. To be able to do this, we don't need to learn anything new, we just need to use what we've already learnt about identifying intervals to find such a note.

Let's say we want to write a note a major 7th above this given note:

As usual, we start with the interval number. The given note is a G, so we need to write an F a 7th above it.

We now have a 7th, but if we identify this interval we will see that it's a minor 7th. We therefore need to raise the note to an F♯ to make it a major 7th.

As you can see, in order to be able to write intervals, you just need to be good at identifying intervals. If you use everything you've learnt and you identify all the intervals correctly at every stage, you should be able to write them easily.
