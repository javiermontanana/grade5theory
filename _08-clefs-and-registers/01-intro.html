If we want to be able to write all the notes in a very wide range, we are going to need to use a lot of ledger lines. In treble clef, to write middle C we already need to use a ledger line, We could use more and more ledger lines to write lower and lower notes, but it quickly becomes hard to read and write these.

By using a different clef, we can centre the stave on a different set of notes, (a different register). This will allow us to write those notes without ledger lines, and we will need ledger lines for any notes outside that range.

The notes on all the various staff positions will also have different letter-names in the different clefs. In this chapter, we will learn about the different clefs, what they mean, how to read notes, and why they are used.
