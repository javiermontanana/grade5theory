What we've learnt so far

In the last section we learnt to identify all the intervals between notes in the C major scale. In the section before that, we learnt about the words major, minor, perfect, augmented and diminished. Here is the chart again showing what they mean.

2nds, 3rds, 6ths, 7ths
diminished minor major augmented
unisons, 4ths, 5ths, 8ves
diminished perfect augmented
← smaller ------ bigger →

Now we can put together everything we've learnt and this will allow us to identify any interval.

If we have an interval with some sharps or flats, we will ignore the sharps and flats to begin with and pretend that both notes are natural. Then we will identify that interval. Once we've done that we can add the sharps and flats one by one. As we add each accidental, we will identify the interval, using the chart above, and taking into account whether the accidental makes the interval bigger or smaller.

Remember that any sharps and flats only affect the interval quality, never the interval number. The number depends only on the staff positions or letter names of the notes, and the first thing we should do is always work out the number.

The first thing we do is work out the interval number. It is a third.

Then we will take away the sharp, identify that interval, then add the sharp back in, and identify that interval.

is one semitone bigger,
so it is a major 3rd

The first thing is to work out the interval number. It is a third.

Then we will take away the sharps and flats and identify that interval. Then we will add the sharps and flats back in, one by one. At every stage we will indetify the interval, so once we have added all the sharps and flat, we will have correctly identified the interval we started with.

C-E is a major 3rd C♯-E is one
semitone smaller, so
it is a minor 3rd		 C♯-E♭ is one
semitone smaller, so
it is a diminished 3rd

Remember that a sharp raises a pitch by a semitone, so if it's on the higher note it will make the interval bigger, but if it's on the lower note it will make it smaller.

Notice also that it wouldn't matter if we had added in the flat first and then the sharp. That would give us the following sequence:

  • C-E is a major third.
  • C-E♭ is a minor 3rd.
  • C♯-E♭ is a diminished 3rd.

The order you choose to add the sharps and flats back in doesn't matter. If you identify the intervals correctly at every stage, you will get the same result.

Congratulations! You can now identify any interval up to an octave! Make sure you get a lot of practice identifying intervals. It will help you understand many other topics in music theory.
