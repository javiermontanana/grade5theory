We have said that a piece of music (or an extract) is in a certain key if it uses notes from that key or scale. We have also learnt about which key signature corresponds to each key. But sometimes the key signature won't tell us what key we are in. Somethimes there will be accidentals which mean that the music is in a different key to that of the key signature.

These are the same extract written 3 times in 3 different ways, with different key signatures. But it is the same extract. It has exactly the same notes and it sounds the same. It is in G major because it uses the notes from G major even though the key signature may not be that of G major.

At the end of the day, a key signature is a tool that makes it easier to write or read certain notes because it helps us avoid writing the same accidentals over and over again, but it doesn't by itself determine what notes are in the music and therefore it doesn't by itself determine the key.

How to find the key

In order to find the key of a musical extract, we need to find what scale the notes used in the extract belong to. We will do this by creating a list of all the notes used. In our list, we are not concerned with what octave the notes appear in, or whether they appear more than once. We will only iclude them once and only in one octave.

Let's do this for the example above. The first note is D. The second note is also D, so we can ignore it, because it is already on our list. The third note is also D, so we can also ignore it (it doesn't matter that it's an octave higher). The next notes are B, G, F♯, E, C. The next notes are B and G, which are already on our list. And finally an A.

So here is our list:
D, B, G, F♯, E, C, A.

Now that we have all the notes, we can put them in a stepwise order to help us find the scale that they all belong to.

Looking at this you should be able to easily spot where the semitones are and through a bit of trial and error, see that they all belong in a G major scale.
