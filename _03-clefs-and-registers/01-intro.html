The staff is basically a grid that allows us to see which notes are higher and lower. In the following example, each note is one step higher than the previous one. but because there is no clef, we don't know what any of the notes are yet. A clef is a symbol that associates a certain pitch with a certain line of the staff. Once we know the pitch for a certain staff-line, we know the pitch for all the other notes.

For example, treble clef places the G above middle C on the second line of the staff. This means we can then assign letter-names to the other staff positions.

To write any notes outside the range provided by the five lines of the staff, we can use ledger lines. To write middle C in treble clef, we need to use one ledger line below the staff.

We can use more ledger lines to write even lower notes, but if we use a lot of them, it quickly becomes hard to read and write these. 0 Instead, we can use a different clef.

Bass clef places the F below middle C on the fourth line of the staff. In bass clef, to write middle C, we need one ledger line above the staff.

The notes that sit within the staff in bass clef are all lower than middle C, and also lower than those that sit within the staff in treble clef. Bass clef places the staff, as it were, in a lower register. Hence bass clef is more suitable for lower notes, or for instruments with a lower register. This is the use of the different clefs: to place the staff in a certain register, to make it easier to read and write the notes within that register.

All the clefs work in essentially the same way: the symbol represents a certain pitch (for treble clef that is the G above middle C, and for bass clef that is the F below middle C) and it is placed on a certain line of the staff, associating that pitch to that staff position.

In the next section you will learn about the four clefs that you need to know for the grade 5 theory exam, including alto and tenor clefs, which use a different symbol, known as a C clef (because it represents the note middle C).
