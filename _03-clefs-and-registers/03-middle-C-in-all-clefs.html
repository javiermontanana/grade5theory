Now that we know what each clef means, we can place a given pitch on any clef. Let's start by placing middle C in all 4 clefs:

Treble Clef

As we learnt earlier, the G-clef symbol represents the G above middle C. The clef is placed on the second line, so counting down from there, we get to middle C, which is on the first ledger line below the staff.
